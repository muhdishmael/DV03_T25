# DV03_T25 - Australian Road Trauma Insights (2011–2021)

Interactive public health data visualisations exploring 11 years of hospitalised road crash injuries in Australia.

## How to Run

You have three easy ways to run the project:

### Option 1: Double-Click (Easiest)
Double-click `start_server.bat` in the project folder. This will start Python's built-in web server and automatically open `http://localhost:8080` in your default browser.

### Option 2: VS Code
- Open this folder in VS Code (`File > Open Folder...`).
- Press `F5` (or click **Run > Start Debugging**). It will automatically run the HTTP server task and open Chrome at `http://localhost:8080`.
- *Alternatively*, right-click `index.html` and choose **"Open with Live Server"**.

### Option 3: Command Line
Open a terminal in this directory and run:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.
